# Правила для Codex

- Працюй українською та перевіряй поточну гілку і `git status` перед змінами.
- Працюй у `feature/integration` для інтеграційних змін. За невідомих змін спочатку запитай власника репозиторію.
- Зберігай наявний код. Не виконуй commit, push чи merge без дозволу користувача.
- Узгоджуй нові API через `docs/API_CONTRACT.md`. Додавай тести до нових маршрутів.
- Не збирай персональні дані й не додавай секрети, бази чи файли відповідей до репозиторію.
- Не змінюй налаштування безпеки Windows.
- Перед передачею змін перевіряй тести, збірку frontend, `git diff --check` і склад файлів Git.
