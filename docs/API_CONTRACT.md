# Попередній контракт API

Статус: чернетка для погодження всією командою. Зараз реалізований лише `GET /api/health`. Решта маршрутів і схеми даних мають бути погоджені власниками модулів до розробки.

## Базові домовленості

- Backend локально працює на `http://127.0.0.1:8000`.
- Маршрути застосунку використовують префікс `/api`.
- Запити та відповіді з даними використовують JSON і UTF-8.
- Ідентифікатори, помилки, правила оцінювання та версіонування потребують командного погодження.
- Персональні дані користувачів не передаються й не зберігаються.

## Реалізований маршрут

| Метод | Шлях | Успішна відповідь | Призначення |
| --- | --- | --- | --- |
| GET | `/api/health` | `200 {"status":"ok"}` | Перевірка доступності API |

## Точки інтеграції, які потрібно погодити

| Модуль | Майбутня відповідальність | Власник |
| --- | --- | --- |
| Сценарії та вибір | Формат сценарію, варіантів і наслідків | Визначає команда |
| Оцінювання | Формат результату й пояснення | Визначає команда |
| Аналітика | Формат підсумку проходження, якщо потрібен | Визначає команда |
| Рекомендації | Формат матеріалів до дилеми | Визначає команда |

Перед додаванням маршруту оновити цей документ прикладом запиту, відповіді та помилки. Потім додати реалізацію і тест.
