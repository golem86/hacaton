# Розрахунок економії часу на підготовці аналітичних матеріалів

Пункт здачі 8. Документ порівнює трудовитрати на один цикл оцінювання: чинний ручний процес (паперові анкети або Excel) і процес у системі Integrity Management Dashboard.

> **Усі години в цьому документі — припущення команди, а не вимірювання.** Хронометраж реального процесу не проводився. Кожне припущення має номер (П1–П10), тож журі чи замовник можуть підставити власні значення й перерахувати підсумок за формулою з розділу 4.
>
> Під час пілотного впровадження припущення варто замінити хронометражем реального циклу.

## 4. Чутливість і формула для перерахунку

**Рядок чутливості ±30% (П10).** Якщо базова економія відхиляється на ±30%, вона становить ≈27,5–51,0 год за цикл, або ≈55,0–102,1 год за рік.

Сценарії, у яких ручні кроки і кроки в системі відхиляються в протилежні боки:

| Сценарій | Вручну, год/цикл | Система, год/цикл | Економія, год/цикл | Економія, год/рік |
| --- | ---: | ---: | ---: | ---: |
| Песимістичний: ручні −30%, система +30% | 34,65 | 13,325 | 21,325 | 42,65 |
| Базовий | 49,50 | 10,25 | 39,25 | 78,50 |
| Оптимістичний: ручні +30%, система −30% | 64,35 | 7,175 | 57,175 | 114,35 |

Навіть у песимістичному сценарії економія становить 21,325 год за цикл, тобто ≈62% часу ручного процесу цього сценарію (21,325 / 34,65).

**Формула.** Від кількості анкет N у моделі залежать лише введення і повторне введення 10% анкет:

- вручну: `41,25 + 0,0275 × N` год за цикл (`0,0275 = 1,1 × 1,5 хв / 60`);
- у системі: `10,25` год за цикл (у спрощеній моделі не залежить від N);
- економія: `31 + 0,0275 × N` год за цикл.

Для N = 300 економія становить 39,25 год. Для N = 1000 (більший заклад, припущення) — 58,5 год за цикл, або 117 год за рік. Модель спрощена: насправді розповсюдження і збирання паперових анкет теж ростуть із N, тож для великих закладів економія, ймовірно, більша.

## 5. Що не враховано

- **Однакове в обох процесах:** час респондентів на заповнення; збирання об'єктивних показників (7 показників для Integrity Index поки вносить лише seed; показники зрілості за Додатком В вносяться через розділ «Об'єктивні показники» й підтверджуються іншим користувачем, але дані для них однаково треба зібрати); наради й ухвалення рішень; контроль виконання рекомендацій.
- **Витрати системи поза П9:** супровід сервера, оновлення, резервні копії, підтримка користувачів.
- **Якісні ефекти, не враховані в годинах:**
  - ніхто не працює з паперовими анкетами, тож почерк чи порядок збирання не розкривають авторів; анонімність закладена в структуру даних ([anonymity.md](anonymity.md));
  - немає помилок ручного введення;
  - приховування малих груп однакове для кожного зрізу й експорту;
  - методика й журнал дій прозорі.

## 6. Що лишається ручним у системі

- Анонімна роздача кодів (організаційне правило: не фіксувати, хто який код отримав; [abuse-analysis.md](abuse-analysis.md), розділ 4).
- Тлумачення результатів і текст аналітичного звіту. Експорт PDF/XLSX містить таблиці підсумку, балів компонентів, участі та балів за категоріями, але не Integrity Index і не висновки (`backend/app/services/reporting.py`, [V2_INTEGRATION_CONTRACT.md](V2_INTEGRATION_CONTRACT.md), розділ 3.3).
- Рішення щодо рекомендацій: система лише пропонує (`status=proposed`, `requires_human_decision=true`).
