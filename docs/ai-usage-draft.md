## 2. Чого ШІ не робить у продукті

- **Під час роботи системи ШІ не використовується.** Integrity Index і рекомендації рахують детерміновані правила на Python: `backend/app/services/scoring.py`, `recommendations.py`. У залежностях `backend/requirements.txt` і `frontend/package.json` немає бібліотек ШІ чи звернень до зовнішніх ШІ-сервісів.
- **ШІ не ухвалює управлінських рішень.** Кожна рекомендація — пропозиція зі статусом `proposed` і `requires_human_decision=true`. Приймає її людина.
- **Дані для ШІ.** Демонстраційні дані синтетичні. За [ai.md](ai.md), персональні дані, службова інформація і секрети до інструментів ШІ не передаються. `[TODO команда: підтвердити це для всіх учасників і всіх інструментів.]`

## 3. Як перевіряли результати ШІ

- `AGENTS.md` вимагає від агента перед передачею змін:
  - перевірити тести, збірку frontend, `git diff --check` і склад файлів у Git;
  - не робити commit, push чи merge без дозволу користувача.
- CI (`.github/workflows/v2-ci.yml`) запускає:
  - backend-тести і frontend-тести;
  - production build;
  - `git diff --check`;
  - перевірку, що в Git немає БД і секретів.
- Числа в `methodology.md` і `objective-comparison-example.md` звірено з кодом: seed запущено на окремій синтетичній БД, результати збігаються з раніше задокументованими (`index=48.4`, 3 пропозиції для циклу 1).
