# Правила безпеки

- Не збирати персональні дані користувачів. Це прямо зазначено в [офіційному завданні](https://hack.bitec.com.ua/wp-content/uploads/2025/11/%D0%97%D0%90%D0%92%D0%94%D0%90%D0%9D%D0%9D%D0%AF-3.pdf).
- Не додавати до Git паролі, токени, ключі, справжні `.env`, бази даних, дампи, логи та файли з відповідями учасників.
- Використовувати лише знеособлені приклади сценаріїв. Перед публікацією перевіряти текст на імена та інші ідентифікатори.
- Перевіряти `git status` і вміст змін перед commit та pull request. `.gitignore` не захищає файли, вже додані до індексу.
- Локальний CORS обмежений адресами frontend. Під час розгортання дозволені джерела слід налаштувати для фактичного домену.
- Секрети, якщо згодом будуть потрібні, зберігати поза репозиторієм і передавати через змінні середовища.
