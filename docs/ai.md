## 2. Що вирішила команда

- **Користувач і проблема.** Керівник закладу й уповноважений з антикорупції не мають чесної картини стану доброчесності: ручне анкетування повільне, а люди не довіряють анонімності.
- **Чому це важливо.** Без чесних даних заходи обирають навмання й не перевіряють, чи вони спрацювали.
- **Принципи:**
  1. анонімність важливіша за деталізацію (поріг k = 5, приховування малих груп);
  2. висновки — лише за явними правилами, які можна показати;
  3. рекомендацію ухвалює людина, система лише пропонує;
  4. відсутні дані не дорівнюють нулю;
  5. дані не виходять за межі нашого сервера.
- **Чого продукт свідомо не робить:** не оцінює й не ранжує людей чи підрозділи, не ухвалює рішень замість посадових осіб, не відправляє дані в хмарні сервіси ШІ.
- **Ключові рішення:** 7 компонентів C1–C7 з найбільшою вагою освітнього процесу ([methodology.md](methodology.md), розділ 3.1); ролі адміністратора призначає лише власник сервера; робочий сервер лише в закритій мережі.

## 3. Що розглянули й відкинули

- **Рішення про рекомендації ухвалює мовна модель** — таке рішення не можна відтворити й пояснити правилом. Залишили правила, а модель лише описує їхній результат текстом.
- **Хмарна мовна модель** — дані оцінювання не повинні залишати сервер.
- **Методика з 3 компонентами й рівними вагами** (`demo-0.2`) — замало для управлінських висновків.
- **Перерозподіл ваг, коли бракує компонента** — індекс «покращувався» б саме тоді, коли зникає найслабше місце.
- **Роль через заголовок `X-Role` і видача ролей у вебі** — відкривали шлях до самопідвищення прав.
- **Перша версія «Результатів підрозділу»** — за малими групами можна було вирахувати відповідь однієї людини. Код відкотили й замінили.

## 4. ШІ в продукті

- **Модель:** Qwen3-8B — модель **з відкритими вагами** (розробник — команда Qwen компанії Alibaba, ліцензія Apache-2.0). Файл `Qwen3-8B-Q4_K_M.gguf` завантажено з Hugging Face і запущено **лише локально** на нашому сервері через llama.cpp (MIT). Модель не звертається в мережу, хмарних ШІ-сервісів, зокрема Qwen Chat чи API Alibaba Cloud, продукт не використовує. Це відповідає п. 2 політики ШІ ([LOCAL_LM.md](LOCAL_LM.md)).
- **Що робить:** пише чернетки текстів з агрегованих даних — резюме циклу, опис уже сформованих правилами рекомендацій і порівняння циклів. Кожне число в тексті автоматично звіряється з даними, а текст показується як чернетка для людини.
- **Чого не робить:** Integrity Index, зони, рівні зрілості й самі рекомендації рахують детерміновані правила (`backend/app/services/`): однаковий вхід дає однаковий результат. Без моделі всі розрахунки, рекомендації й звіти працюють; недоступними стають лише чернетки текстів.
